# phro-pm-terms

Claude의 답변에서 **IT 업계 PM이 알아둬야 할 기술 약어·개념**을 골라 체크리스트로 모아 주는 Claude Code mod입니다.

Claude가 답을 마칠 때마다 답변에서 용어 후보를 뽑아 새 것만 Haiku에 보내고, 결과를 체크리스트에 더합니다. 각 항목은 다음처럼 정리됩니다.

- **용어**: 약어는 풀네임을 괄호로 붙여 `WER(Word Error Rate)`처럼 보여 줍니다. 풀어 쓴 용어(`Hot reload`)는 그대로입니다.
- 개념적 의미 한 문장
- `예)` 실제 적용 예시 한 줄

## 중복 관리와 토큰 절약 규칙

용어는 로컬 JSON 파일 `~/.claude/phro-pm-terms/terms.json` 하나에 쌓입니다. 중복 판단은 전부 이 파일로 로컬에서 하고, Haiku에는 답변 원문도 기존 용어 목록도 보내지 않습니다.

1. **후보 추출(로컬)**: 코드 블록·인라인 코드·URL·파일 경로를 먼저 걷어낸 뒤, 약어(`API`, `CI/CD`)와 한국어 문장 안의 영어 표현을 정규식으로 뽑습니다. 저장소 이름·`--옵션`·`file.ts`처럼 다른 문자에 붙은 토큰과 커밋 해시는 후보에서 뺍니다.
2. **정규화 키로 거르기(로컬)**: 소문자로 바꾸고 괄호·공백·`-`·`_`·`.`를 지운 키로 비교합니다. 이미 모은 용어의 키와 별칭(풀네임·한글명·표기 변형), 그리고 예전에 Haiku가 탈락시킨 단어(`ignored`)와 겹치면 뺍니다.
3. **새 후보가 없으면 Haiku를 부르지 않습니다.** 있으면 후보 단어만(최대 40개) 쉼표로 보냅니다.
4. **Haiku는 주어진 후보 안에서 고르고 합치기만** 합니다(새 용어를 지어내지 않음, CLI 명령·제품 기능명 제외). PM에게 의미 있는 것만 최대 8개, 같은 대상을 가리키는 후보는 하나로 합치고 별칭을 붙여, JSON 대신 `용어 | 별칭 | 의미 | 예시` 한 줄 형식으로 답합니다.
5. **탈락한 후보는 `ignored`에 기록**해 다시는 보내지 않습니다. 같은 단어에 두 번 비용을 쓰지 않습니다.
6. **중복은 이름으로만 판단**합니다. Haiku가 같은 용어를 다른 말로 설명해도 새 용어로 추가하지 않고 처음 설명을 유지합니다. 키·별칭에 더해 여러 단어 용어의 머리글자(`Continuous Integration` → `ci`)도 비교해서 `CI`와 `Continuous Integration`은 하나로 봅니다. 제거한 용어도 중복으로 잡혀 다시 추가되지 않습니다.
7. 파일 읽기·쓰기는 한 번에 하나씩 처리하고, Haiku 응답을 받은 뒤 파일을 다시 읽어 합칩니다. 추출이 겹치거나 다른 세션이 그사이 파일을 고쳐도 결과를 덮어쓰지 않습니다. 파일이 깨져 있으면 빈 목록으로 덮어쓰지 않고 알림만 띄웁니다.

## 설치

```bash
claude plugin marketplace add ThatsHoon/phro
claude plugin install phro-pm-terms@phro
```

## 사용

| 명령 | 동작 |
|---|---|
| `/pm-terms` | 체크리스트 패널 열기 |
| `/pm-terms scan` | 현재 세션의 지난 답변 전체에서 용어 추출 (후보 40개씩 최대 5번) |
| `/pm-terms stats` | 지금까지 Haiku 호출 수·실패 수·입출력 토큰 누적과 호출당 평균 |

패널 상단에 `배울 용어` / `보관` / `제거` 세 탭이 있습니다.

- **배울 용어**: ☐를 누르면 보관으로, **제거**를 누르면 제거 탭으로 옮겨집니다.
- **보관**: ☑를 누르면 배울 용어로 돌아가고, **제거**로 제거 탭에 보낼 수 있습니다.
- **제거**: 관심 없는 용어를 모아 둡니다. 여기 있는 용어는 다시 추출돼도 추가되지 않습니다. **복원**을 누르면 배울 용어로 돌아갑니다.

목록은 위 JSON 파일 하나에 저장되고 모든 세션이 같은 파일을 씁니다. 각 세션은 3초마다 파일 변경을 확인해 패널을 다시 그리므로, 한 세션에서 옮긴 용어는 다른 세션에서도 같은 탭에 보입니다. 파일을 직접 열어 고쳐도 반영됩니다.

## 비용

새 후보가 있을 때만 Haiku를 한 번 호출합니다(입력은 후보 단어 목록, 출력 최대 960 토큰). 실제 사용량은 `/pm-terms stats`로 확인합니다. 서브에이전트 턴, 중단·에러로 끝난 턴에서는 호출하지 않습니다.

쌓인 용어가 많아져도 호출당 토큰은 늘지 않습니다. Haiku에는 기존 용어 목록을 보내지 않고, 이번 답변에서 처음 보는 후보만 40개까지 보내기 때문입니다(실측 211회 평균 입력 438, 출력 477 토큰). 용어가 쌓이며 커지는 것은 로컬 파일뿐입니다(용어 258개, 제외 단어 718개에 약 100KB).

## 알려진 문제

- **패널 버튼이 가끔 눌리지 않음(0.5.0까지):** 용어가 늘지 않은 추출(제외 단어만 늘어남)이나 다른 세션의 파일 변경에도 패널을 다시 그렸습니다. 다시 그릴 때마다 버튼 식별 번호가 바뀌어, 그사이 누른 버튼은 처리되지 않았습니다(데스크톱 로그의 `ui_press not handled`). 0.5.1부터는 용어 목록이 실제로 바뀔 때만 다시 그립니다.
- **패널에 "Nothing to show yet"만 보임:** 패널을 연 세션의 엔진이 다시 시작되면(앱 재시작, 세션 재연결) 화면에는 패널 자리가 남지만 새 엔진은 그 패널을 열지 않은 상태라 그릴 내용이 없습니다. `/pm-terms`로 다시 열면 됩니다.
