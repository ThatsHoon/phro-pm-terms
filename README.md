# phro-pm-terms

Claude의 답변에서 **IT 업계 PM이 알아둬야 할 기술 약어·개념**을 골라 체크리스트로 모아 주는 Claude Code mod입니다.

Claude가 답을 마칠 때마다 Haiku가 답변을 읽고 용어를 최대 8개 추출합니다. 각 항목은 다음처럼 정리됩니다.

- **용어**
- 개념적 의미 한 문장
- `예)` 실제 적용 예시 한 줄

이미 모은 용어는 대소문자 구분 없이 걸러서 중복으로 쌓이지 않습니다. 새 용어가 들어오면 `📘 PM 용어 N개 추가` 토스트가 뜹니다.

## 설치

```bash
claude plugin marketplace add ThatsHoon/phro
claude plugin install phro-pm-terms@phro
```

## 사용

| 명령 | 동작 |
|---|---|
| `/pm-terms` | 체크리스트 패널 열기 |
| `/pm-terms scan` | 현재 세션의 지난 답변 전체에서 용어 추출 |

패널 상단의 `학습할 용어 (n)` / `보관함 (n)` 탭으로 전환합니다. ☐를 체크하면 학습 목록에서 사라지고 보관함으로 옮겨지며, 보관함에서 ☑를 다시 누르면 학습 목록으로 돌아옵니다. 목록은 세션이 바뀌어도 유지됩니다.

## 비용

답변이 끝날 때마다 Haiku를 한 번 호출합니다(최대 2,000 토큰). 서브에이전트 턴, 중단·에러로 끝난 턴에서는 호출하지 않습니다.
